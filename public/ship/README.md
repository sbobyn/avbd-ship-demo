# Dutch Ship Medium

Source: https://polyhaven.com/a/dutch_ship_medium
License: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/
Authors: James Ray Cock (model, textures, cleanup), Nicolò Zubbini (original model),
Rico Cilliers (sails model, textures).

The 1K glTF asset is stored locally so the demo does not depend on a runtime asset CDN.
`ship.gltf` is the original `dutch_ship_medium_1k.gltf`, renamed; referenced files are unchanged.
`manifest.json` records source URLs and SHA-256 checksums. Restore/verify files with
`node scripts/fetch-ship.mjs` from the repository root.
